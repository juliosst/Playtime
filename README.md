<h1><strong>Setup</strong></h1>
<ol>
<li>Set the time with <span style="color:#f1c40f">/clock time</span>.</li>
<li>Now set the maximum playing time for each person with <span style="color:#f1c40f">/max-playtime 0 0 2</span>. This will set the maximum playing time to 2 hours.</li>
<li>If desired, you can set when the game time is reset with <span style="color:#f1c40f">/clock reset 12 0 0</span>. The game time will then be reset at 12:00:00.</li>
</ol>
<p>&nbsp;</p>
<h1><strong>Settings</strong></h1>
<p>You can configure various settings using /settings.</p>
<p>Usage: /settings module true/false</p>
<p>Modules: <span style="color:#f1c40f">actionbar, debug, kick_operators, reset_all, reset_settings</span></p>
<p>The <span style="color:#f1c40f">reset_all </span>and <span style="color:#f1c40f">reset_settings </span>modules allow you to reset either everything or just the settings. These modules must be <span style="color:#f1c40f">executed twice</span> for confirmation.</p>
<p>&nbsp;</p>
<h1><strong>Playtime</strong></h1>
<p>The playtime can be displayed in two different ways: once via the <span style="color:#f1c40f">/playtime</span> command and once by setting the actionbar to true via <span style="color:#f1c40f">/settings actionbar true</span>.</p>
